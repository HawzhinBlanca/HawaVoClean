# 07 - Restoration Benchmarks

**Honest headline:** on these synthetic, non-holdout fixtures, every restoration method
*degrades* mean fullband LSD relative to doing nothing. The untouched degraded input
scores 6.52 dB; HawaRestore-KD (personalized) scores 9.55 dB, generic 9.60 dB, and the
official UniverSR neural baseline 15.57 dB (LSD is lower-is-better). This benchmark
therefore measures **pipeline integrity** — that every method runs end-to-end, metrics
compute deterministically, and the protected band stays bounded — **not product
quality**. Evaluation on real, held-out Kurdish speech is user-gated (U3: user-approved
corpus collection) and has not happened yet.

## What actually ran

All numbers below come from [benchmark_results.json](./benchmark_results.json),
regenerated 2026-08-24 by:

```
PYTHONPATH=. .venv/bin/python research/restoration/benchmark.py
```

| Run parameter | Value |
|---|---|
| `universr_mode` | `neural` — official `woongzip1/universr-speech` weights, sha256-verified against the in-repo registry, flow-matching inference on `mps` |
| `seed` | 42 (degradation simulator RNG) |
| `cutoffs_hz` | 4000, 7500, 12000, 16000 |
| `test_set_provenance` | `synthetic_profile_fixtures, non-holdout` |
| Speakers | 10 synthetic profiles (`character_01`..`character_10`), 160 result rows |
| Degradation | 8th-order Butterworth lowpass at each cutoff; no additive noise, no packet loss |

### Test-set provenance (read this before trusting any number)

The test signals are the 10 canonical profile WAVs under `profiles/` — 3-second
formant-filtered pulse trains generated by `research/restoration/profiles_builder.py`.
No human speaker exists. These are the **same recordings the personalized model
conditions on**, so this is a non-holdout evaluation and cannot demonstrate
generalization.

## Summary (mean over 10 synthetic speakers x 4 cutoffs)

| Method | Fullband LSD (dB, lower better) | Highband LSD (dB, lower better) | Protected-band RMS err (lower better) | Speaker cosine sim (higher better) |
|---|---|---|---|---|
| Degraded input (do nothing) | **6.52** | **8.20** | **0.00085** | 0.945 |
| UniverSR baseline (`neural`) | 15.57 | 19.80 | 0.00167 | **0.971** |
| HawaRestore-KD (generic Kurdish) | 9.60 | 11.64 | 0.00157 | 0.960 |
| HawaRestore-KD (personalized) | 9.55 | 11.58 | 0.00157 | 0.959 |

## What these numbers do and do not show

1. **Restoration currently loses to doing nothing on aggregate.** Only at the 12 and
   16 kHz cutoffs does HawaRestore-KD reach parity with the degraded input
   (4.43 vs 4.46, 3.49 vs 3.59 dB); at 4 and 7.5 kHz it is substantially worse. Any
   claim that restoration improves quality is not supported by this benchmark.
2. **Speaker similarity is measured by the in-repo deterministic mel-DSP
   `SpeakerEmbeddingExtractor`** (`src/hawavoclean/restoration/speaker_embed.py`) —
   **not** 3D-Speaker or any neural speaker-verification model. The values (0.945-0.971)
   are not comparable to published speaker-verification scores, and the spread between
   methods on synthetic fixtures is too small to support timbre-preservation claims.
   Note the UniverSR baseline scores highest (0.971) on this metric.
3. **Protected-band invariance holds.** All methods keep protected-band RMS error at or
   below 0.00167 on these fixtures, consistent with the protected-band merge design.
4. **Baseline mode is now recorded.** `UniverSRBaseline` silently falls back to
   deterministic DSP spectral extrapolation when the official neural weights cannot be
   loaded, and the two modes produce very different numbers (a previous DSP-fallback
   run reported mean fullband LSD 9.18 dB for UniverSR vs 15.57 dB neural). Earlier
   committed copies of `benchmark_results.json` did not record which mode ran, and a
   stale contradictory copy at the pack root has been deleted. The output JSON now
   carries `universr_mode` so this ambiguity cannot recur.

## Reproduce

```
PYTHONPATH=. .venv/bin/python research/restoration/benchmark.py
```

`research/restoration/configs/benchmark_manifest.json` (cutoffs, speakers, seed). The
console output and the JSON both state the `universr_mode` that actually ran.
